QR-Based Hostel Maintenance Reporting System

  • Python
  • Flask
  • SQLite
  • HTML
  • CSS
  • JavaScript
  • QR Code

Problem

Hostel maintenance complaints can be difficult to track when students rely on informal reporting methods.

Solution

A QR-based digital reporting system that connects a physical hostel location to an online maintenance reporting form.

Key Features

  • QR-code-based reporting per hostel block
  • Image-supported maintenance reports
  • Admin management dashboard
  • Complaint status tracking
  • Database storage with SQLite
  • Hostel / block identification
